SEC 03 / HOW A LIVE EVENT COMES TOGETHER

  1. Net stands up the segmented terrain — VLANs, isolation, DNS lockdown, QoS.

  2. Engine deploys the range onto VLAN 20 — CTFd, MultiJuicer, analyst workstations.

  3. Wargames validates fail-closed and loads 59 challenges into CTFd — the administrator starts each track independently.

  4. Each operator's laptop carries the Agent loadout — a friendly coaching AI running locally, installed with one command.

  5. Event tracks every remaining task until doors open.
